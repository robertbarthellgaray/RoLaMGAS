The full heliocentric file uses that separate cruise variant; it is not the unchanged baseline case above. The Titan-centered file contains only atmospheric entry and descent. Model release location 18.350 degrees N, 154.220 degrees E, after 144.18 minutes. Predicted peak aerodynamic deceleration 20.62 Earth g, compared with the published Dragonfly study limit of 12 g; this simplified model is not a survivability validation. This shows that an entry subpoint over the intended site does not deliver a landing there. The model is not validated as the operational Dragonfly EDL trajectory.
